# Как тратить меньше токенов на бесплатном Claude

Claude считает токены, а не сообщения. В каждом ответе он заново читает весь чат, поэтому длинный чат дорожает с каждым сообщением.

## Главное
1. **Один маленький кусок работы = один чат.** Закончил часть, взял архив, начал новый чат.
2. **Не повторяй в чате то, что уже есть в архиве.** В `START-HERE.md` теперь есть раздел TOKEN ECONOMY: новый чат читает только нужное. Начинай чат строкой из `site/AI-NOTES.md` (раздел "The line to paste into a new chat").
3. **Пиши всё нужное одним сообщением**, а не тремя. Правка: пиши, что именно изменить, а не "переделай".
4. **Прикладывай только нужные файлы.** Для мелочи хватит одного файла, а не всего архива. Большие PDF и картинки дорогие.
5. **Выключай ненужное.** Веб-поиск, Research, коннекторы и артефакты тратят лимит. Включай их только когда нужны.
6. **Простые вопросы задавай на лёгкой модели** (Haiku), сложную работу оставь для Sonnet или Opus.
7. **Следи за лимитом:** Settings → Usage. Сессия идёт пятичасовым окном, плюс есть недельный лимит.

## Раз в несколько частей
Старый текст переезжает в папку `history/` (так делает Claude по правилам START-HERE). Если файлы `AI-NOTES.md` и `CHANGELOG.md` снова распухли, попроси: "перенеси старое в history".
