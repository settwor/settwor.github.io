# Как добавить текст песни

1. Pages CMS → **Lyrics** → New.
2. **Name of the song**: название песни ровно так, как оно написано в треклисте (например, `Doomshop`).
3. **Artists**, **Release** (необязательно, показывается под названием).
4. **Web address**: `/lyrics/doomshop/` (маленькие буквы, дефисы вместо пробелов).
5. **Words of the song**: вставьте текст. Пустая строка начинает новый куплет, переносы строк сохраняются.
6. Сохраните. Через минуту после сборки сайта в окне релиза рядом с этим треком появится кнопка **Lyrics**.

Версии трека `(sped up)`, `(slowed)`, `(ultra sped up)`, `(Alternate Mix)`, `[Bonus Track]` открывают тот же текст, отдельную страницу для них делать не нужно.

Если кнопка не появилась: название песни не совпало с названием в треклисте (проверьте буквы, апострофы, регистр не важен).
