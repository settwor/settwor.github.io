{%- comment -%} v11.39 (languages, Phase 4). Replaces bio-router.html. NO automatic redirect by browser language any more (Google advises against it; todo i18n D5). What this script does: 1. Remembers the language the visitor picks in a language list (a link with hreflang), key `settwor-bio-lang` (the same key as before). 2. Links marked data-bio-link (the Biography links of English pages) lead to the biography of the REMEMBERED language only; without a remembered choice they keep the English address that is in the HTML. 3. On an ENGLISH page that has ready versions in other languages (its translation group: the biographies today, more pages later), a visitor whose browser language is one of those languages sees one quiet, dismissable bar just above the footer (11.71; it was above the header before): "This page is also in " with a plain link. The visitor is never moved by script. A dismissed bar stays hidden (key `settwor-lang-hint`). A Ukrainian browser is never offered Russian when a Ukrainian version is missing (rule kept from 2.4). The group is found like in lang-switch.html (page.ref; the biographies are the group "bio"). Only READY versions are listed (i18n_ready: false is left out).
